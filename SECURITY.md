# Security policy

LevPlay is pre-mainnet and does not currently accept real funds. Do not send assets to addresses presented by unofficial builds or messages.

Report suspected vulnerabilities through GitHub private vulnerability reporting. If that channel is unavailable, email info@levplay.tech with the subject `SECURITY` and request an encrypted reporting channel before sending sensitive details. Never include seed phrases, private keys, API secrets or personally identifying wallet information.

We aim to acknowledge reports within two business days, provide an initial severity assessment within five business days, and coordinate disclosure after a fix is available. Good-faith research using local validators, paper mode or accounts you control is welcome; do not access third-party funds or data, degrade services, or publicly disclose an unresolved issue.

Reports should include the affected commit, component, impact, reproduction steps, minimal proof of concept and suggested remediation. Findings involving unauthorized access to real third-party assets are not accepted; use local validator fixtures or accounts you control.

Before public mainnet availability, LevPlay requires a funded severity-based bug bounty, safe-harbor terms, response targets and an independent Solana audit/retest for the exact release binary.

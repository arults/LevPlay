# Security policy

LevPlay is pre-mainnet and does not currently accept real funds. Do not send assets to addresses presented by unofficial builds or messages.

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature once enabled. Do not include seed phrases, private keys, API secrets or personally identifying wallet information.

Reports should include the affected commit, component, impact, reproduction steps, minimal proof of concept and suggested remediation. Findings involving unauthorized access to real third-party assets are not accepted; use local validator fixtures or accounts you control.

Before public mainnet availability, LevPlay requires a funded severity-based bug bounty, safe-harbor terms, response targets and an independent Solana audit/retest for the exact release binary.

# LevPlay SBF program shell

This crate is the native Solana entrypoint around `levplay-core`. It is
intentionally non-custodial and non-value-moving at this stage: every
well-formed instruction returns `EXECUTION_LOCKED_ERROR` after strict wire
decoding.

That lock is a security property, not a launch implementation. It must remain
until program-owned configuration/state, PDA derivation, Token-2022 or SPL
Token CPI, dual-oracle validation, the isolated backing-vault path, nonce
persistence and transaction-introspection checks are implemented and
independently audited.

Builds are pinned to `solana-program = 2.2.0`. Production SBF artifacts must
be generated by the repository workflow with a verified Agave toolchain and
must match the hashes in the release-evidence manifest. No deploy keypair or
upgrade-authority key belongs in this repository.
